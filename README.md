# C Programming From Basic

This repository is a beginner-friendly collection of C programming exercises and example programs. It is organized by topic to help learners practice the fundamentals of C step by step.

## Repository Structure

- `variable/` — programs focused on variables, declarations, assignments, and basic input/output
- `make_decision/` — examples using conditional logic such as `if`, `else`, comparisons, and decision-making
- `Program_Looping/` — programs demonstrating loops and repeated execution patterns
- `Array/` — examples covering arrays, character arrays, array initialization, and simple algorithms
- `LICENSE` — repository license

## Topics Covered

- Variables and data types
- Basic arithmetic and expressions
- Decision-making with conditions
- Looping structures
- Arrays and string-like character arrays
- Simple C program exercises

## Prerequisites

To compile and run the C programs, you need:

- A C compiler such as GCC
- A terminal or command prompt

## Compile and Run

Each example is usually stored as a standalone `.c` file. You can compile it with GCC:

```bash
gcc variable/lesson_1.c -o lesson_1
./lesson_1
```

You can replace `variable/lesson_1.c` with any other source file from the repository.

Example for an array program:

```bash
gcc Array/Array_init.c -o Array_init
./Array_init
```
